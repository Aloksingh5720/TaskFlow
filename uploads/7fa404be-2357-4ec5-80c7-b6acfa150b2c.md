## 🔑 Key Concepts

### Core Entities
- **Merchant**: Payout service customer
- **Beneficiary**: Payment recipient
- **LiveTransfers**: Transaction records
- **Vendor**: Payment service provider (RazorPay, Axis Bank, etc.)
- **Daemon**: Background status checker

### Transaction States
- **Pending**: Initiated, awaiting vendor response
- **Success**: Completed successfully
- **Failed**: Transaction failed
- **Expired**: Payout link expired

### Key Features
- **Multi-Vendor Routing**: Route transactions to different vendors
- **Charge Configuration**: Custom charges per merchant
- **Balance Management**: Wallet-based balance tracking
- **Webhook Notifications**: Real-time status updates
- **Bulk Transfers**: CSV-based batch processing
- **Payout Links**: Shareable payment links

## 📝 Code Conventions

### Package Structure
```
com.payripe.payouts/
├── config/        # Security, filters, listeners
├── controller/    # Request handlers
├── service/       # Business logic
├── repository/    # Data access
├── model/         # JPA entities
├── deamon/        # Scheduled jobs
├── vendorapis/    # External API integrations
└── utils/         # Helper utilities
```

### Naming Conventions
- **Entities**: `LiveTransfers`, `Merchant`, `Beneficiary`
- **Repositories**: `LiveTransfersRepository`, `MerchantRepository`
- **Services**: `LiveTransfersService`, `MerchantService`
- **Controllers**: `TransfersController`, `BeneficiaryController`
- **Daemons**: `NexaPayStatusAPIDeamon`, `RazorPayStatusAPIDeamon`

## 🚀 Getting Started

### Prerequisites
- Java 8+
- Maven 3.6+
- MySQL 5.7+

### Setup Steps
1. Clone repository
2. Create database: `CREATE DATABASE payouts_db;`
3. Update `application.yml` with DB credentials
4. Run: `mvn spring-boot:run`
5. Access: `http://localhost:8089`

### Configuration Files
- `application.yml`: Server, database configuration
- `application.properties`: Vendor URLs, email settings

## 🔧 Development Tips

### Adding a New Vendor
1. Add vendor URLs to `application.properties`
2. Create `VendorNameAPIController.java` in `vendorapis/`
3. Create `VendorNameStatusAPIDeamon.java` in `deamon/`
4. Add credentials to `mid_keys` table
5. Configure routing in `merchant_routing` table

### Adding a New API Endpoint
1. Create method in appropriate controller
2. Add service layer logic
3. Create repository method if needed
4. Add API documentation to `05_api_endpoints.md`

### Debugging Transactions
1. Check `live_transfers` table for transaction status
2. Check `allapi_req_res` table for API logs
3. Check `status_check_by_deamon` table for daemon logs
4. Check application logs for errors
